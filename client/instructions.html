📡 REST API Usage

Simple Chat Request

Send a single message and get a response:

curl -X POST http://localhost:3847/api/chat \ -H "Content-Type: application/json" \ -H "X-Harvey-Auth: Harveylocalmodel01" \ -d '{"message": "Hello, Harvey! How are you?"}'

Chat with Conversation History

Send multiple messages to maintain context:

curl -X POST http://localhost:3847/api/chat \ -H "Content-Type: application/json" \ -H "X-Harvey-Auth: Harveylocalmodel01" \ -d '{ "messages": [ {"role": "user", "content": "My name is Alex"}, {"role": "assistant", "content": "Nice to meet you, Alex!"}, {"role": "user", "content": "What is my name?"} ] }'

Streaming Response

Get a streaming response for real-time output:

curl -X POST http://localhost:3847/api/chat/stream \ -H "Content-Type: application/json" \ -H "X-Harvey-Auth: Harveylocalmodel01" \ -d '{"message": "Write a short poem about coding"}'

Response Format

{ "success": true, "response": "Hello! I'm doing great, thank you for asking...", "role": "assistant", "conversationId": "uuid-here", "model": "Google Gemma 27B" }

🔌 WebSocket Connection

JavaScript Example (Browser)

// Connect to Harvey via Socket.IO const socket = io('http://localhost:3847', { auth: { password: 'Harveylocalmodel01' } }); // Handle connection socket.on('connected', (data) => { console.log('Connected to Harvey:', data.message); }); // Send a message socket.emit('chat', { message: 'Hello Harvey!', stream: true // Enable streaming }); // Receive streaming chunks socket.on('chat_chunk', (data) => { process.stdout.write(data.chunk); }); // Receive complete response socket.on('chat_complete', (data) => { console.log('\\nFull response:', data.response); }); // Handle errors socket.on('chat_error', (data) => { console.error('Error:', data.error); });

Node.js Example

const { io } = require('socket.io-client'); const socket = io('http://localhost:3847', { auth: { password: 'Harveylocalmodel01' } }); socket.on('connect', () => { console.log('Connected!'); socket.emit('chat', { message: 'Explain quantum computing in simple terms', stream: false }); }); socket.on('chat_response', (data) => { console.log('Harvey:', data.response); socket.disconnect(); });

WebSocket Events

chat Send: {message, stream}
chat_response Receive: Non-streaming response
chat_chunk Receive: Streaming chunk
chat_complete Receive: Stream complete
clear_conversation Send: Clear history
get_history Send: Get chat history

🐍 Python Example

Using Requests

import requests url = "http://localhost:3847/api/chat" headers = { "Content-Type": "application/json", "X-Harvey-Auth": "Harveylocalmodel01" } data = { "message": "What is machine learning?" } response = requests.post(url, json=data, headers=headers) result = response.json() print(f"Harvey: {result['response']}")

Using Socket.IO

import socketio sio = socketio.Client() @sio.event def connect(): print('Connected to Harvey') sio.emit('chat', {'message': 'Hello!', 'stream': False}) @sio.on('chat_response') def on_response(data): print(f"Harvey: {data['response']}") sio.disconnect() sio.connect('http://localhost:3847', auth={'password': 'Harveylocalmodel01'}) sio.wait()

🌍 Remote Access

To access Harvey from other devices on your network:

  1. Find your computer's local IP address (shown above or run ipconfig/ifconfig)
  2. Ensure your firewall allows connections on port 3847
  3. Use the network URL instead of localhost
💡 Tip: For access outside your local network, consider using a reverse proxy like ngrok or setting up port forwarding on your router.

🔧 Troubleshooting

Connection Refused

Make sure the Harvey server is running: npm start

401 Unauthorized

Check that you're including the correct password in the X-Harvey-Auth header or socket auth.

Model Not Found

Download the model: ollama pull gemma2:27b

Ollama Not Running

Start Ollama: ollama serve

Slow Responses

The Gemma 27B model requires significant RAM (~16GB+). Consider using a smaller model if performance is an issue.
